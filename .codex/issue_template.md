## Описание

Кратко описать цель задачи: что нужно добавить, изменить или проверить, и зачем это нужно проекту.

Зависит от: #<номер_issue_если_есть>.

## Что нужно сделать

- Описать первый конкретный пункт работы.
- Описать второй конкретный пункт работы.
- Описать n-й конкретный пункт работы.
- Указать важные сценарии, которые нужно покрыть.
- Указать ограничения или границы задачи, если они есть.
- Если задача зависит от будущего merge другой ветки, явно добавить:
  - после merge `<название_фичи>` дополнительно сделать `<что именно>`.

## Критерии готовности

- Изменения реализованы в рамках текущей архитектуры проекта.
- Добавлены или обновлены необходимые тесты.
- Проверки проходят:
  - `poetry run ruff format .`
  - `poetry run ruff check .`
  - `poetry run mypy .`
  - `poetry run pytest`
- Нет лишних зависимостей, неиспользуемого кода и несогласованных изменений.
