# coding_style.md

- придерживаться PEP 8;
- имена переменных, функций, классов и файлов только на английском языке;
- не использовать сокращения типа msg, usr, cfg, obj, tmp;
- предпочитать ранний return вместо глубокой вложенности;
- не использовать глобальные переменные;
- использовать константы вместо магических чисел и строк;
- одна функция должна решать одну задачу;
- избегать функций длиннее 50 строк без острой необходимости;
- удалять неиспользуемые импорты, переменные и функции;
- использовать f-строки вместо format() и конкатенации строк;
- предпочтительно использовать list comprehensions там, где это улучшает читаемость.
