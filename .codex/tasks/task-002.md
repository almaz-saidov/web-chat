## Исправить опечатку в названии файла dependesies.py

### Контекст

В проекте присутствует файл:

```text
src/api/dependesies.py
```

Название файла содержит опечатку.

Корректное название:

```text
src/api/dependencies.py
```

### Что нужно сделать

1. Переименовать файл:

```text
src/api/dependesies.py
↓
src/api/dependencies.py
```

2. Найти все импорты, использующие старое имя файла.

3. Обновить импорты на новое название.

4. Убедиться, что приложение запускается без ошибок импорта.

### Проверки

После изменений проверить:

* отсутствуют импорты `dependesies`;
* все импорты используют `dependencies`;
* приложение успешно стартует.

### Ожидаемый результат

Предоставить отчет:

* какие файлы были изменены;
* какие импорты были обновлены;
* прошел ли запуск приложения после переименования.
